# DualMirror／雙鏡

[English](README.md) | **繁體中文**

**Windows 檔案比較與合併工具。**

左右並排比較資料夾、文字與二進位檔案，在同一個視窗查看差異、編輯文字及合併內容。
支援多個比較分頁；再次開啟比較工作時會加入既有視窗，相同配對則切回原分頁。

目前版本：**0.1.0**。
從 [GitHub Release](https://github.com/jerrygskk/DualMirror/releases/tag/v0.1.0) 下載 `DualMirror.exe`，不需另裝 Python。

## 主要功能

| 功能 | 說明 |
| --- | --- |
| 資料夾比較 | 左右資料樹同步展開、選取與捲動，可篩選差異、相同及單側檔案。 |
| 兩階段檢查 | 先快速比較大小與修改時間，再依需要檢查實際內容。 |
| 文字比較與編輯 | 直接修改文字、搜尋取代、復原，支援 19 種語言樣式與 26 種編碼選項。 |
| 差異合併 | 點選箭頭合併整個差異區塊，或選取完整文字行後複製到另一側。 |
| 二進位比較 | 以唯讀十六進位檢視內容，插入與刪除以空位對齊，保留各側原始位址。 |
| 檔案操作 | 複製到另一側或指定資料夾、單側重新命名，以及移至 Windows 資源回收筒。 |
| 外部異動監看 | 切回視窗時依左、右側詢問是否更新；只更新同意的側，寫入前再核對磁碟版本。 |
| Windows 11 右鍵整合 | 從檔案總管選取兩個檔案或資料夾比較，也可先指定左側，再選另一個項目比較。 |

## 從原始碼啟動

目前在 **Windows 11、Python 3.12（64 位元）** 環境驗證。

下載或複製本專案後，在專案資料夾開啟終端機，執行：

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

也可雙擊根目錄的 `啟動.cmd`。此啟動檔使用目前帳號預設安裝位置的 Python 3.12；若 Python 裝在其他位置，請使用上面的啟動指令。

直接帶入兩個檔案或兩個資料夾：

```powershell
py -3.12 main.py "C:\Compare\left.txt" "C:\Compare\right.txt"
py -3.12 main.py "C:\Compare\left" "C:\Compare\right"
```

## 基本操作

### 比較資料夾

1. 指定左右兩側資料夾，程式會自動比較大小與修改時間。
2. 需要核對實際內容時，按「詳細比較」；選取項目則只檢查選取範圍，未選取時檢查全部。
3. 雙擊檔案，在新分頁查看文字或十六進位內容。

中央的 `=`／`≠` 表示已檢查內容的結果。留白表示尚未驗證、僅單側存在，或該列為資料夾。
**大小與修改時間相同，不代表內容已確認相同。**

### 編輯與合併文字

- 兩側文字都可直接編輯；金色箭頭複製整個差異區塊。
- 點選文字行或拖曳行號，可選取完整行，再以藍色箭頭複製選取範圍。
- 合併先修改記憶體中的內容，按「儲存」才寫回檔案。
- 語言選單控制語法上色；編碼選單可重新解讀檔案，存在未儲存變更時無法切換編碼。
- 搜尋與取代範圍依序為「雙側、左側、右側」，預設雙側；雙側全部取代可一次復原。
- 按「× 關閉」或 `Esc` 收起搜尋／取代列，輸入內容會保留。

### 拖入檔案比較

- 一次拖入兩個檔案，依拖入順序放在左、右側；新增比較分頁，相同配對重用。
- 單個檔案拖到文字或 Hex 的左、右內容區，只替換該側；有未儲存內容時先確認。
- 單個檔案拖到工具列、分頁列或起始畫面不會替換；拖拉開檔不接受資料夾。

### 外部檔案變更

切回視窗時，程式會檢查目前分頁的檔案；兩側都被外部修改時，先問左側、再問右側。
只更新同意的側；拒絕後，同一次變更不重複詢問。更新會捨棄該側未儲存修改，確認框會明確提醒。

| 快速鍵 | 操作 |
| --- | --- |
| `Ctrl+S` | 儲存目前側 |
| `Ctrl+Shift+S` | 目前側另存新檔 |
| `Ctrl+F` | 搜尋 |
| `Ctrl+H` | 搜尋與取代 |
| `Ctrl+Z`／`Ctrl+Y` | 復原／取消復原 |
| `Ctrl+W` | 關閉目前分頁 |
| `F5` | 重新整理資料夾比較 |

### 從檔案總管開啟比較

在程式「整合」選單選擇「註冊右鍵整合」，確認後即可使用 Windows 11 右鍵入口。
目前的註冊方式需要 Windows 開發人員模式；程式不會自動開啟此設定。
可隨時選擇「取消註冊右鍵整合」，原有字型與比較設定會保留。

## 資料保護與使用限制

- 「複製／同步」保留來源及目的端多餘檔案，不會把目的端刪成與來源完全一致；同名檔案可能被覆寫，執行前會確認。
- 儲存會保留目前編碼、BOM 與未修改部分的換行；無法編碼時停止寫入。
- 另存新檔輸出副本，不切換目前比較配對，也不清除原檔的未儲存狀態。
- 刪除使用 Windows 資源回收筒，失敗時不會改用永久刪除；不支援操作連結。
- 自動編碼偵測可能有歧義，請依內容確認，必要時手動選擇。
- 十六進位比較維持唯讀，目前整檔保存在記憶體中；大型檔案會增加記憶體需求。
- 大量重複內容可能存在不同的有效對齊方式，不保證差異數最少。
