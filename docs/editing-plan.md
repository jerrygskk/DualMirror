# 文字修改實作計畫

使用者已同意前次建議的第一輪四項：直接編輯、選取行合併、搜尋取代、另存新檔。
沿用 Python 3.12、PySide6 及現有公版，不新增相依、不打包、不註冊右鍵。

1. 新增真實暫存檔的 Qt 測試，先確認上述功能尚不存在。
2. 文字編輯仍以獨立原始字串為準，建立顯示位置對原始文字的對應。
   對齊補行不寫入；中文輸入、貼上、刪除、取代及合併共用復原歷史。
3. 方向按鈕有來源選取時只複製選取行，無選取時維持整個差異區塊。
4. 搜尋列加入取代欄、取代目前及全部取代；預設處理目前側、字面比對。
5. 檔案選單加入目前側儲存與左右另存。另存輸出保留編碼與換行，不切換原比較路徑。
   目的檔存在時確認覆寫，寫入前再核對目的快照，禁止覆寫原比較的兩端。
6. 執行語法與直接相關測試；用暫存檔跑完整打字、合併、取代、另存流程，
   確認 1280×750 可操作並關閉測試視窗。這輪不 commit。

風險驗證：NBSP／非 BMP 字元、混合換行、對齊空白列、輸入法、外部修改、
不存在側、另存編碼失敗與覆寫競態。
