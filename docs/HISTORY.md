# DualMirror 版本紀錄

近期版本摘要放在 [DEVELOPER.md](DEVELOPER.md)，已發布的歷史版本留在本檔。

## 0.1.0（2026-11-12）

2026-11-11 由維護者指定初始版號，2026-11-12 以原版號首次發布。
發布頁：[v0.1.0](https://github.com/jerrygskk/DualMirror/releases/tag/v0.1.0)。
提供 Windows onefile `DualMirror.exe` 及 `SHA256SUMS.txt`，含下列功能與本輪更新。

- 再次啟動交給既有視窗，相同配對重用；內容讀取及初次對齊使用背景工作。
- 搜尋取代提供「雙側、左側、右側」範圍，預設雙側；可用關閉按鈕或 Esc 收起。
- 拖入兩個檔案新增比較，單檔拖到左／右內容區替換該側，未儲存內容先確認。
- 外部檔案變更於切回視窗時依左後右詢問，只更新同意的側；拒絕同一版本不重複詢問。

- Windows 雙欄檔案／資料夾比較、快速資訊比較與手動詳細內容比較。
- 同視窗文字編輯與區塊／選取行合併，搜尋取代、復原及另存新檔。
- 唯讀 Hex 內容對齊、原始位址、紅色差異總覽及跳轉。
- 獨立中央內容結果區，保留拖曳分隔、展開、選取與捲動同步。
- 單向複製、同步、重新命名及資源回收筒操作。
- 正式名稱 DualMirror／雙鏡；B 相融造型，深藍／琥珀圖示。
- 建立 onefile spec、Qt 瘦身及版本資訊工具，固定開發環境與相依版本。
- Windows 11 原生右鍵、固定資源快取與 Python／EXE 啟動器；原始碼版已實測，onefile 的真實右鍵註冊仍未實測。
- 啟動最大化；單側／兩側上移；主工具列圖示下加文字、下拉動畫及起始畫面，所有比較分頁皆可關閉。
- 金色區塊箭頭與範圍括號；文字及行號拖曳產生藍色自訂合併範圍，合併後維持檢視位置。
- 修正 IME 組字誤存補位換行、重複字元游標跳動、左右列高不一致及補位斜線接縫。
- 文字配對優先相同非空白行；新增 19 種語言樣式及 26 種編碼選項，支援自動偵測與手動指定。
- 資料夾清單採逐側狀態圖示、父層彙整、合計大小、檔案色塊及交錯列底色，不再整列標紅。

2026-11-12 追加定案：資料夾及單側檔案改用深鋼藍，複合圖示正面斜切採深鋼藍；
淡藍反白只改背景，保留圖示與狀態文字原色。兩個單檔啟動不再額外開資料夾列表；
文字分頁新增可編輯路徑與左側選檔按鈕，順序為「選擇檔案、路徑欄、儲存」，其他功能位置保留。
換檔先驗證並保護未儲存內容，相同配對重用分頁，獨立內容分頁仍支援外部刷新。

2026-11-12 配色階段擴大測試 245 項通過；單檔流程相關測試 53 項通過，最後位置調整相關 3 項通過。
兩項先前遇原子替換存取被拒的測試未重跑，最後單檔調整後亦未重新跑完整測試，
不代表完整測試全過。各項可見視窗驗證與已知限制詳見 [DEVELOPER.md](DEVELOPER.md)。
上述為單檔調整階段的驗證紀錄，不是首次入庫前的最新狀態。
