原始碼的 manifest 位於 `shell/AppxManifest.xml`；建立註冊用固定資源複本時，仍放在複本根目錄，
原生 DLL 等檔案則放在該複本的 `shell/` 下，維持 Windows 註冊格式。
`packaging/version_info.txt` 為忽略的生成檔；根目錄不保留舊模組或轉接副本。
目錄整理後完整 260 項測試通過，含非目前目錄的資源定位、frozen 資源、版本工具與打包宣告。
已用 Windows 可見視窗從其他工作目錄啟動，確認圖示、資料夾比較及第二次啟動的文字分頁；

Python 3.12＋PySide6 桌面工具，提供左右比較、資料樹與分頁操作。
文字區參考 Notepad++ 的行號欄、目前行、搜尋與狀態資訊；區塊操作支援復原／取消復原。
工具列與狀態圖示由 `tools/create_icons.py` 產生自製 SVG。
向量定義在 `tools/icon_design.py`：路徑瀏覽圖示暖金、一般操作藍；資料夾清單另用灰、紅、鋼藍及混合色摘要內容。

雙擊 `啟動.cmd`；也可用正式 Python 執行 `main.py`。
`main.py 左路徑 右路徑` 支援直接帶入兩個檔案或兩個資料夾。
主程式啟動直接最大化。帶入兩個檔案時直接開內容分頁、不建立多餘的資料夾分頁，兩個資料夾只開清單，
不自動拿資料夾清單第一項開文字比較。兩個文字檔直接開文字分頁；非文字檔可開唯讀 Hex 分頁，資料樹按 `=?` 才詳細驗證內容。
文字支援左右直接編輯、選取行合併、搜尋取代及另存新檔。

## 已定案行為

- 「全部檔案」以全形 `＊` 圖示呈現，相同檔案為黑色。
- 主工具列使用圖示下方短文字，移除已有文字按鈕的 tooltip；其他純圖示按鈕仍保留提示。
  tooltip 背景淡化為 `#fffff5`。全域下拉框使用一般清單模式 `combobox-popup: 0`，
  從欄位下緣展開，不蓋住欄位與箭頭，並沿用 Qt 內建下拉動畫。
- 左右單側上移使用暖金資料夾箭頭，中央兩側上移使用 A 雙窗格圖示；僅對資料夾有效。
  任一側無法上移時，兩側上移不執行部分移動；單側仍可各自操作，上移後自動比較。
- 資料夾、文字及 Hex 分頁都可關閉，不能再以「索引 0」判斷不可關閉。
  最後一頁關閉後顯示起始畫面，可新增資料夾比較；關閉資料夾工作階段會清除路徑、清單及監看，
  不連帶關閉內容分頁。忙碌時不能關閉資料夾頁，未儲存文字仍有捨棄確認。
- 左右都指定有效且同類型的路徑後自動比較，任一側換路徑也自動重新偵測；輸入未完成時不跳錯誤框。
- 初次載入、自動刷新與 F5 只比大小、修改時間，不讀取整批內容。`=?` 詳細比較選取項目及選取資料夾的子項目，
  未選取時比較全部；結果與 tooltip 區分「資訊相同／不同（未檢查內容）」及「內容相同／不同」。
- 左右資料樹之間的獨立窄區顯示內容結果：黑色 `=`、紅色 `≠`；未驗證、單側及資料夾留白。
  `lib/ui/comparison_gutter.py` 以自訂 QSplitterHandle 繪製，固定窄寬且保留分隔拖曳，
  使用左樹目前可見列的位置對齊，不依附表格欄位、水平捲動或選取底色。
  中央上移按鈕由啟用的外層容器承接滑鼠事件，即使按鈕停用也不向分隔條傳遞拖曳；
  按鈕區維持一般箭頭游標，只有下方內容結果區可左右拖曳。
  左樹 viewport 重繪、捲動及展開狀態改變時更新。開啟 Hex 的實際結果也回傳資料夾清單。
  F5 僅在檔案大小、修改時間、建立時間及檔案識別未變時沿用結果；檔案／資料夾變動通知
  一律使相關內容結果失效，背景掃描期間收到通知也不得恢復舊結果。
- 開啟文字分頁直接讀取並比內容；同步規劃及覆寫前仍驗證實際內容，不以相同大小／時間作為寫入安全依據。
- 左右比較樹同步選取、展開與捲動；雙擊檔案於同視窗開分頁，同一對檔案不重複開啟。
- 資料夾清單採逐側狀態語意，以完整掃描結果逐側向父層彙整；不比較資料夾時間來決定紅色。
  資料夾名稱為黑色、合計大小及日期灰色。圖示有灰、紅、鋼藍、灰藍及紅藍：
  紅表示包含較新或不同項目，鋼藍表示含此側獨有項目，混合色表示同時包含對應狀態。
  灰圖示不代表內容已驗證相同，可能含相同或較舊項目；整個單側資料夾為鋼藍色。
  檔案以名稱／大小／日期及小色塊標示黑（相同）、紅（較新或不同）、灰（較舊）、鋼藍（單側）。
  內容確認相同會取消原先時間差的顏色；內容不同但時間較舊的一側仍灰。清單另顯示交錯列底色。
- 單邊存在的文字檔也能開分頁；缺檔端標示「檔案不存在，無法操作」並停用，區塊複製與該側儲存不可執行，
  不自動建檔；監看偵測到該檔新增／移除時同步更新可操作狀態。
- 多選檔案或資料夾可複製到另一側，或另選目的資料夾。
- 同名不同內容整份覆寫，缺檔與空資料夾補齊；來源及目的端多出的檔案都保留。
- 批次操作只跳精簡確認框，顯示新增／覆寫數量，不開大型明細視窗。
- 複製、同步與文字儲存後自動重新比較；保留資料樹展開、選取與捲動位置，不清空後要求使用者按 F5。
- QFileSystemWatcher 監看目前左右範圍的檔案與各層資料夾，外部異動也觸發刷新；短時間多個事件合併處理，
  背景工作或確認框結束後再執行。原子替換後重新掛上檔案監看；關閉視窗即停止監看與待執行刷新。
- 外部異動會更新乾淨的文字分頁；未儲存合併保留，儲存前仍核對磁碟版本，避免覆蓋其他程式的修改。
- 文字區塊合併只修改記憶體，明確儲存才寫入；Qt 顯示文字不得當原始資料。
- 直接打字、中文輸入、剪貼、取代及區塊合併共用復原／取消復原。
  對齊顯示的 UTF-16 位置映射回獨立原始字串；只取本次新增片段，不用整份 toPlainText 覆蓋資料。
  Qt 修改 document 時只更新原始字串，下一個事件才重建對齊，避免在修改回呼內重建 document。
  補行輸入會建立真正的文字行；刪除純顯示補行不修改原始內容。
- 每個差異區塊都有約 16×16 金色實心箭頭與細灰區間括號，箭頭操作區寬 24px，與行號分開。
  點文字行、拖曳選取或拖曳行號，會在來源側生成藍色自訂箭頭及對應括號；
  行號左方沒有箭頭的空白區也能整行選取，向上／向下拖曳皆支援。

  箭頭提示只顯示複製方向，不增加行數說明。合併後保留來源側檢視位置與左右對齊，

  禁止用另存覆寫目前比較的兩端；其他既有目的檔確認一次，原子替換前核對目的快照。

## 文字對齊、輸入與樣式

文字差異的 SequenceMatcher 不將空白行用作主要錨點，優先配對相同文字後再安排前後空白。
空白差異仍會顯示與合併，不等同詳細比較的忽略空白規則；重複文字仍可能有其他有效配對，
不保證唯一配對結果。

`AlignedDocumentLayout` 讓兩側文字、真實空白及顯示補位共用相同行高，避免 Consolas 與中文字型
回退導致 16／18px 等差距逐行累積。跳轉後也同步兩側起始捲動位置；字型變更透過視窗所屬的
單次 QTimer 重算，不能留下視窗銷毀後仍執行的匿名回呼。自訂 document layout 保留 Python 強參照。

新增／不同文字以紅字、淡紅底呈現，區塊中的真實空白行淡紫底；缺行側不顯示假行號，
目前區塊採斜線、其他區塊採交叉斜線。底紋在 viewport 以整個連續補位區間繪製，
不逐行重設圖樣起點；保留選取底色與游標區域，底紋不進入原始字串或輸出檔案。

IME 可能只改組字格式，卻通知整段文字移除／加入；原先直接使用此範圍，會將顯示補位換行
誤寫回原文，造成連打 `11` 後換行或游標跳動。現在將通知範圍內真正變動的文字縮小後，
再經 UTF-16 映射回 `self.texts`。比較用的 Qt 正規化快照與原文分離，避免 NBSP 等正規化損害資料。
IME 提交另保留實際插入位置，避免在重複字元中誤把游標移到整串末端；仍不在修改回呼內重建 document。

路徑下方的語言與編碼選單左右獨立。`lib/ui/syntax_styles.py` 使用 Pygments，提供純文字、Python、
C、C++、C#、Java、JavaScript、TypeScript、HTML、CSS、JSON、XML、YAML、SQL、INI、Shell、
PowerShell、批次檔與 Markdown，共 19 種。依副檔名優先，未知副檔名僅採足夠明確的內容判斷，
無法確認則純文字。完整原文分詞後映射到對齊顯示，支援跨行語法及非 BMP 字元；只改文字色彩，
不改比較規則、原文或字型。差異標示優先於語法色彩。所有列出樣式均有自動測試及可見視窗樣本驗證。

`lib/core/text_encoding.py` 提供自動偵測及 26 種明確編碼選項，涵蓋 UTF-8／16／32、BOM 與位元組順序、
繁簡中文、日韓文、Windows 及 DOS 等字碼頁。先處理 BOM／嚴格 UTF-8，再使用 charset-normalizer；
無 BOM Unicode 必須符合保守的零位元組規律，短二進位檔不因此直接當作文字。
偵測不是確定判定，短文字及多種編碼皆可解讀的位元組仍可能有歧義，可手動指定。
切換只重新解讀原始位元組；任一側尚有未儲存變更時禁止切換。錯誤不以替代字元略過，
保留原內容及原選擇；成功後重設乾淨的復原紀錄。手動選擇保留於目前配對並套用後續外部刷新，
不新增全域設定。儲存仍使用目前解讀的編碼，保留 BOM、位元組順序與未改部分的換行。
spec 已列入所需 Pygments lexer 及 friendly 樣式，但本輪未重新打包驗證。

已移植成本專案副本，不跨專案 import，不帶來源業務、機關署名或發布流程。
`tools/pyi_prune.py` 保留 SVG／ICO／Windows 平台外掛及 Python SSL。
未使用的 UI 檔載入與資料庫錯誤處理已從共用元件移除；不再強制收錄 QtUiTools／OpenGL 連結期 DLL。
spec 收錄正式 `assets/` 圖示、manifest 與必要 Shell 檔案，排除開發套件及未使用的 QML 綁定。

產品名稱與版本唯一來源為 `lib/settings/version.py`；由維護者決定版號後才執行：

```powershell
& $python tools/bump_version.py 0.1.0
```

`packaging/version_info.txt` 是生成檔，不入庫；新環境只要重建相同版本資訊即可，不必進版：

```powershell
& $python tools/bump_version.py --regenerate
& $python tools/export_app_icon.py
```

主圖示正式來源是 `assets/DualMirror.svg`，`assets/DualMirror.ico` 含 16／24／32／48／64／128／256
像素透明圖示。主視窗已使用正式圖示及 `DualMirror v0.1.0` 標題。
暫存設計稿與候選圖不作為打包來源；`tools/create_icons.py` 仍只處理既有工具列／Shell 圖示。

以下為維護者明確要求打包時的完整命令；2026-11-11 已實際執行。
`$python` 設為上列正式 Python，先確認目前在專案根目錄。

```powershell
$projectRoot = (Get-Location).Path
foreach ($directory in @('build', 'dist')) {
    $target = [System.IO.Path]::GetFullPath((Join-Path $projectRoot $directory))
    if ((Split-Path $target -Parent) -ne $projectRoot) { throw '打包清理路徑不在專案根目錄。' }
    if (Test-Path -LiteralPath $target) { Remove-Item -LiteralPath $target -Recurse -Force }
}
& $python tools/bump_version.py --regenerate
& $python -m PyInstaller --clean --noconfirm packaging/DualMirror.spec
```

預期主程式產物 `dist/DualMirror.exe`，onefile、無主控台、無 UPX。

## 公開 Git 儲存庫與上傳範圍

GitHub 儲存庫：[jerrygskk/DualMirror](https://github.com/jerrygskk/DualMirror)，維護者指定公開。
本地分支為 `main`，`origin` 指向此儲存庫；建立儲存庫不代表已 commit 或推送。

`.gitignore` 參考公文系統：暫存／快取、打包產物、資料庫與備份、記錄、交接表、
本機個資名單、憑證及使用者設定排除。保留本工具必要的 spec、正式資源、Shell DLL／啟動器，
以及 docs 的技術與圖示設計資料。`.gitattributes` 固定 Windows 腳本為 CRLF。

`tools/check_no_pii.py` 移植公文系統的通用掃描，不帶入資料庫與種子資料檢查。
本機比對名單位於 `tests/pii_denylist.local.txt`，不入庫；新環境需另備有效名單，不能以空名單替代。
檢查安全工作樹、暫存區、HEAD、待推送的每個提交完整內容，以及未排除的候選檔案。
不跟隨儲存庫外的連結，命中只顯示檔名；無名單、空名單或一般模式缺少 upstream 時失敗。
支援 UTF-8、帶 BOM 的 UTF-16／UTF-32 與 CP950；其他不可辨識內容回報未完成，不視為乾淨。

```powershell
# 首次推送前（尚無追蹤分支），包含全部本地提交；未 commit 時仍檢查候選檔及暫存區。
& $python tools/check_no_pii.py --initial
# 已有追蹤分支時，只加查尚未推送的提交。
& $python tools/check_no_pii.py
# 保護機制的測試只使用虛構名單與隔離 Git 儲存庫。
& $python -m pytest tests/test_no_pii.py -q --basetemp .tmp/pii-check
```

檢查通過只代表未命中本機已知名單，不是所有個資或金鑰的保證；圖片與二進位檔仍需另外確認。
`.gitignore` 不會移除已被追蹤的檔案；新增檔案仍逐檔加入並確認實際入庫內容。
