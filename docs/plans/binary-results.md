# 內容比較結果

使用者已同意：資料夾內容比較符號、Hex 紅色差異總覽、二進位插入／刪除對齊。
另要求完成後實際開啟主程式操作試跑。

1. 新增暫存檔測試：插入、刪除、替換、相同、缺檔、多處差異及原位址保留。
2. `lib/core/binary_alignment.py` 使用標準庫建立內容對齊區段；小區段比位元組，
   大區段先用內容決定切點的區塊尋找共同錨點，再細分差異。
   對齊由本工具實作；重複資料可能有不同但有效的配對。
3. `lib/ui/hex_compare.py` 使用區段映射顯示位元組及原位址，空缺不顯示假位元組。
   左側加紅色縮圖、目前可見範圍、點擊跳轉；重載時更新對齊及總覽。
4. `main.py` 左樹最右方加窄結果欄；只有內容已驗證才顯示黑色＝或紅色≠。
   打開 Hex 的實際比較結果回傳清單；相同檔案快照刷新時保留，檔案改變即失效。
5. 語法及相關測試後，以 Windows 真實主程式配暫存樣本試跑並核對 1280×750，
   截圖保存 `.tmp/`；關閉試跑程序，不動使用者原有視窗。

不調整既有快速比較的時間容許值、不編輯二進位、不打包、不 commit。
