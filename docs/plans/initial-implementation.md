# 檔案比較實作計畫

使用者已核可功能與開工；由主程序直接實作，不新增核可關卡。

目標：建立 Python 3.12 / PySide6 雙欄桌面比較工具。
介面複製 PoliceDocSys 公版；標準庫負責比較與寫入，不新增套件。

## 範圍與檔案
- lib/core/core.py：遞迴掃描、位元組比較、文字編碼與差異區塊、安全寫入、單向同步。
- lib/ui/text_compare.py：左右文字、行號、差異標色、區塊複製與儲存。
- main.py：左右路徑、資料夾比較表、篩選、同步預覽與背景工作。
- lib/ui/theme.py / lib/ui/ui_common.py：來源公版副本；不修改其他專案。
- tests/：全用暫存資料驗證真實讀寫。

## 資料安全
同步由使用者選方向，新增與整份覆寫，不刪除目的端多餘檔案。
文字區塊操作只修改記憶體，明確儲存才寫入，保留目的端編碼與換行。
寫入前核對來源與目的端內容；外部修改後拒絕寫入。暫存檔寫完再原子替換。
連結不跟隨；重疊資料夾與檔案/資料夾衝突拒絕複製，避免寫到預期範圍外。
